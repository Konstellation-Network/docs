# Upgrade History

Konstellation has not launched a network, so there is no upgrade history
yet. This page will list, in order, every chain upgrade that has gone out on
any network — each entry linking to its writeup in
[`networks/<net>/upgrades/`](https://github.com/konstellation-network/networks),
which carries the halt height, binary URL, SHA256 checksum, and any
`config.toml`/`app.toml` changes operators need to make.

| Network | Upgrade | Height | Date | Notes |
|---|---|---|---|---|
| — | — | — | — | first upgrade will appear here |

Operators should not need to read source code to upgrade — if a real
upgrade ships and this page doesn't have enough detail to act on, that's a
docs bug against this repo.
